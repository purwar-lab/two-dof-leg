# Two-DOF Leg Arduino Motion Playground

Standalone interactive webpage for setting hip/knee servo angles, inserting Arduino commands, and previewing leg motion.

## Publish on GitHub Pages

1. Upload the `two-dof-leg` folder to the root of your existing GitHub Pages repository.
2. Ensure GitHub Pages is enabled for the branch/folder containing your website (`Settings` > `Pages`).
3. Visit `https://YOUR_USERNAME.github.io/two-dof-leg/` for a user/organization site, or `https://YOUR_USERNAME.github.io/REPOSITORY/two-dof-leg/` for a project site.

Alternatively, upload just `two-dof-leg/index.html` as the root `index.html` of a new repository if you want the simulator as its homepage.

The simulator is self-contained and does not require dependencies or a build step. It previews a limited set of Arduino motion commands; it is not an Arduino compiler or hardware emulator.
